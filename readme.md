# ASSEMBLE 2026 – Marvel Themed Event Website

This is a Marvel-themed event website for **ASSEMBLE 2026**, a 24-hour hackathon by the **GeeksforGeeks Student Chapter, Bennett University**.
I made it for the Junior Core Technical Team, Round 1.

## 💡 Concept

The idea behind the website is the Avengers: every participant is a "hero" who assembles with a team to save the world through code.

- The **6 hackathon tracks** are shown as the **6 Infinity Stones**:
  - Space Stone – Cloud & DevOps
  - Mind Stone – AI / ML
  - Reality Stone – AR / VR & Games
  - Power Stone – Web3 & Security
  - Time Stone – Open Innovation
  - Soul Stone – Social Impact
- The **"Which Avenger are you?"** section matches each hero to a team role (for example, Spider-Man = Frontend, Thor = Backend). When you click a hero, the colour of the whole website changes to match that hero.
- The design uses a dark cinematic background with Marvel red and gold, comic-style dots, and bold Bebas Neue headings, like a movie poster.

---

## ✨ Features

- Live countdown timer to the event
- Rotating rings and animations in the hero section
- Moving strip with the event highlights
- Infinity Stone track cards with hover effects
- Hero picker that changes the website's theme colour
- Schedule with Day 1 / Day 2 tabs
- Prize section with 1st, 2nd and 3rd place cards
- FAQ accordion
- Registration form with input validation and a success message
- Fade-in animations while scrolling
- Fully responsive (mobile, tablet and desktop) with a mobile menu
